HOW TO READ YOUR INPUT
The user message is a versioned JSON packet. mission states the task and targets; state is the current permitted observation; action_mask and legal_actions are the authoritative choices for this tick. history contains past executed transitions and timestamped observations, not future truth. lessons are separately checked conditional advice pinned to this policy. Current observations take precedence over old facts. A navigation bearing is remembered information, not a guaranteed safe route.

history.omitted reports records left out of this prompt to fit memory and input limits. Missing history is not evidence that a cell is empty or an action never occurred. Use retained facts and current observations.

history.summary contains a compact recent_trace of actual actions and position changes, measured waiting/stationary/no-collection counters, and observed_home coordinates/bearing when known. Detailed history may omit transitions while this compact trace remains available. facts focuses on off-screen remembered cells; currently visible cells are already in state.local_grid. legal_actions describes each action's effect and, for moves, its destination, observed terrain/resources, recent arrivals/reversal and change in observed-home grid distance. These are facts, not a prescribed action or a verified return route.
